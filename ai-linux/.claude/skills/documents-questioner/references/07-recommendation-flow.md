## 7. 目的別のおすすめ実行フロー

18個の共通質問を毎回すべて実行する必要はありません。目的に合わせて選びます。

### 7.1 短時間で全体像をつかむ

```text
1. 重要論点
2. 合意点・独自主張・対立点
3. 不確実性・情報不足
4. エグゼクティブサマリー
```

### 7.2 意思決定を行う

```text
1. 重要論点
2. Claim-Evidence Matrix
3. 前提条件・適用範囲
4. 反証・例外・失敗条件
5. 選択肢とトレードオフ
6. 優先順位付け
7. Decision MatrixまたはADR
```

### 7.3 実行計画へ落とし込む

```text
1. ベストプラクティスとアンチパターン
2. 統合チェックリスト
3. 障壁・失敗要因と対策
4. 実践ロードマップ
5. 効果測定・KPI
6. AIエージェント向け実行指示
```

### 7.4 ソースの信頼性を検証する

```text
1. Claim-Evidence Matrix
2. ソース自体の評価
3. 前提条件・適用範囲
4. 反証・例外・失敗条件
5. 不確実性・情報不足
6. 追加調査
```

### 7.5 基本の7ステップ対話

```text
Step 1:
このソース群の主要論点を整理してください。

Step 2:
重要な主張と、それを支持・留保するソースを整理してください。

Step 3:
ソース間の合意点、対立点、前提条件の違いを分析してください。

Step 4:
今回のソースだけでは判断できない事項と、結論を変えうる追加情報を挙げてください。

Step 5:
以上を踏まえ、選択肢とトレードオフを整理してください。

Step 6:
私たちのContextは次のとおりです: [Context]
この条件ではどの選択肢が適切か、根拠・留保とともに提案してください。

Step 7:
採用する案を、実行計画、チェックリスト、KPI、検証方法に変換してください。
```
