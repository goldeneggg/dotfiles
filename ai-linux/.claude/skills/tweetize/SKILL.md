# Tweetize

## 入力と出力

テキストを受け取り、既定でカジュアルな日本語の投稿案を1件返す。
130文字はこのSkill独自の上限であり、プラットフォームの公式上限ではない。
文字数は改行を含むUnicodeコードポイント数で数える。

## 手順

1. 最も伝えたい内容と、維持する事実を特定する。
2. URL、メンション、ハッシュタグ、固有名詞、重要な日時・数値、原文保持が必要な引用を抽出する。
3. 保持要素だけで130文字を超えないか確認する。
4. 事実を変えず、冗長な接続や修飾を削って圧縮する。
5. 完成本文を実測し、130文字以内であることと保持要素を確認する。
6. 本文と `文字数: N / 130` を返す。

## 保持と表現

URL・メンション・ハッシュタグは原文を保ち、短縮URLサービスを使わない。
引用は原則保持し、要約する場合は元の直接引用であるように見せない。
事実、日付、数値、製品名を勝手に変更しない。
煽りや評価を原文以上に強めない。
絵文字はユーザーが求めた場合だけ使う。

## 不可能な条件

保持要素だけで130文字を超える場合は、要素を黙って削ったり再生成を無期限に繰り返したりしない。
必要文字数を示し、上限変更または保持要素の選択が必要と伝える。
ユーザーの判断前に、条件を満たした投稿案として出力しない。

## 複数案

求められた場合だけ、異なる表現の候補を最大3案提示する。
各案を個別に実測する。
ユーザーが別の件数を明示した場合は、その指定を優先する。
