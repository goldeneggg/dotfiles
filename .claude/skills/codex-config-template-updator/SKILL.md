# Codex Config Template Updator

`ai-linux/.codex/config.template.toml` をユーザースコープ用テンプレートとして扱い、公式サンプルとの差分を判断する。実機の `~/.codex/config.toml`、プロジェクト設定、テンプレート外の設定例は変更しない。

## 情報収集

1. リポジトリルートを確認し、対象を `ai-linux/.codex/config.template.toml` に固定する。ファイルが存在しなければ停止して報告する。
2. 行数を確認する。500 行を超える場合は関連箇所を検索してから、250 行以下ずつ EOF まで読む。`#####-TEMPLATE-BEGIN` と `#####-TEMPLATE-END` の間だけを更新対象にする。
3. 最新の公式サンプルを [Sample Configuration](https://learn.chatgpt.com/docs/config-file/config-sample) から取得する。閲覧日と URL を記録する。説明が必要な項目は同ページからリンクされる公式 Config reference を確認する。
4. 公式ページを取得できない場合は更新を行わない。取得失敗と、確認が必要な URL を報告する。非公式記事や記憶で公式サンプルを補完しない。

## 比較と更新

設定キー、配列テーブル、通常のテーブルを親テーブルを含む完全修飾名で比較する。コメント、直前の説明、関連する子キーを一つの設定単位として扱う。行頭の空白を除いて `#` で始まるものを無効、そうでない TOML 構文を有効と判定する。

| テンプレート | 公式サンプル | 実施内容 |
| --- | --- | --- |
| 無効 | 無効 | 公式を正として、キー名、値、許容値、コメント、テーブル構造が古い場合だけテンプレートを更新する。 |
| 有効 | 無効 | 値と有効状態を維持する。変更が有益なら推薦のみを出す。 |
| 無効 | 有効 | 有効化しない。値または有効化が有益なら推薦のみを出す。 |
| 有効 | 有効 | 値と有効状態を維持する。変更が有益なら推薦のみを出す。 |

公式だけに存在する項目は、テンプレート境界内の対応するセクションへすべてコメントとして追加する。設定単位の直前コメント、親テーブル、子キーを公式の順序と値で保持する。親テーブルがテンプレートにない場合は親テーブルと子キーの全行をコメント化し、親テーブルが有効の場合は子キーだけをコメント化する。追加によってテーブルまたはキーを有効化してはならない。テンプレートだけに存在する項目は、公式で廃止または互換性に懸念があることを公式資料で確認できた場合のみ、影響を添えて推薦する。ユーザーが明示的に求めない限り、前記の推薦は適用しない。

## テンプレート固有の保護

- `$VAR` 形式、特に `$CODEX_CONFIG_YOUR_HOME_DIR` は反映先で実値へ置換する目印である。変数展開、リネーム、実パス化、引用符の除去をしない。
- ローカルの日本語コメント、利用意図、`FIXME` は保持する。公式コメントの置換・追加は、両方で無効な設定単位の更新、または公式のみの設定単位のコメント追加に限定する。
- `#####-TEMPLATE-END` の後ろにあるプロジェクト固有 Permission Profiles 設定例は比較・更新しない。
- 秘密情報、認証トークン、実在のホームディレクトリ、ローカル OAuth 資格情報をテンプレートや報告へ追加しない。

## 推薦の基準

推薦は、公式仕様との不整合、無効な値、セキュリティ・プライバシー・権限拡大、保守性、または現行の明示意図との矛盾に限る。好みだけの提案や、既存のカスタム値を既定値へ戻す提案は避ける。

各推薦には、対象の完全修飾キー、現状、提案値または操作、理由、リスクまたはトレードオフ、適用の有無を明記する。設定の有効化、権限緩和、ネットワーク許可、テレメトリー、外部コマンドの変更は、必ず「未適用」としてユーザーの明示承認を待つ。

## 検証と報告

1. 更新後に差分を確認し、変更がテンプレート境界内かつ「両方無効」の設定単位の更新、または公式のみの設定単位を完全にコメント化した追加だけであることを確認する。後者でテーブルまたはキーが有効化されていないことも確認する。
2. 変更した構文が TOML として妥当かを検証する。テンプレート変数は文字列のまま扱い、検証のために置換しない。
3. 次を簡潔に報告する。
   - 公式 URL と閲覧日
   - 自動更新・追加した設定単位と理由、または「更新なし」
   - 未適用の推薦（該当時のみ）
   - 検証結果と、比較対象外にしたテンプレート外の設定例

不明な項目、公式サンプルの取得不能、または TOML 検証失敗がある場合は、テンプレートを変更せず、根拠と次に必要な判断を報告する。
